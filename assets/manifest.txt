# Store Express - audio asset manifest
#
# Format:  logical_name|filename|loopable|source_url|bytes
#
#   logical_name  key the game uses (unused at runtime, kept for readability)
#   filename      file the game loads from the live assets/ directory
#   loopable      1 if the game keeps this playing as a loop, 0 for one-shot
#   source_url    where the first-run bootstrap downloads the real recording from
#                 (leave empty to always use the bundled placeholder tone)
#   bytes         the exact size of the recording behind source_url, as fetched
#                 and verified. Optional; leave empty if you do not know it.
#
# On first run the bootstrap walks this list, downloading each source_url into
# assets/<filename>. If a download fails after all retries, the matching file in
# assets/placeholder/ is copied in instead, so the game is always playable.
#
# The bytes column is a repair check, and it is worth the trouble of filling in.
# A download that stopped early leaves a file that still plays, just clipped, so
# nothing at runtime can tell it from a whole one. Without a known size the
# bootstrap cannot either, and because it skips anything already on disk, the
# damage would last forever. With the size recorded, a file of the wrong length
# is deleted and fetched again on the next run. Blank means no check.
#
# Every non-empty source_url below was verified to return HTTP 200 with real
# Ogg Vorbis / MPEG / WAV audio bytes, every file was verified to load and play
# in the engine, and every one is public domain, CC0, or
# attribution-only. Most come from Wikimedia Commons; the sound effects come from
# Freesound's public preview CDN. See CREDITS.md for the attribution each one
# requires.
#
# The filename's extension must match the container the URL really serves: the
# recording is written to disk exactly as downloaded, byte for byte, and the game
# loads it by that name. Hence the mix of .ogg, .mp3 and .wav below.
#
# The codec matters as much as the container. The engine decodes Vorbis, MP3 and
# WAV, but NOT Ogg Opus. A file can be a perfectly valid .ogg and still be silent
# here, which is exactly what happened to the old Gas-Pump-sound.ogg: it is an Ogg
# container holding Opus, so it never loaded and the forecourt pump was silent
# for as long as that URL was in this file. Its replacement above is an MP3. If
# you add a recording, check the codec (ffprobe or `file`) before trusting it.

# NOTE: upload.wikimedia.org rate limits bursts of requests with HTTP 429, which
# is why the bootstrap paces its requests and backs off. If you see 429s, the
# bootstrap simply falls back to the bundled tones and you can re-run later.
#
# NOTE: the files downloaded at runtime are the Freesound *previews*, not the
# original uploads. The preview is the file the sound's licence covers for public
# streaming and redistribution, and it is deliberately short: tv.mp3 is the
# longest at three minutes, and every one-shot effect is under six seconds.
#
# NOTE: a one-shot cue plays its file to the end, so a *loop* recording must
# never be used as a one-shot. The shoplifter's rustle used to be the shop
# ambience file, which meant a whole minute of mall noise for a rustle at a
# shelf; it has a four second cue of its own now.

# ---- the floors and the walls ------------------------------------------------
# Every floor has a recording of its own - a boot on the shop's vinyl tile, a
# shoe on the office carpet, a step on bare concrete in the walk ins, the gravel
# of the forecourt - and every floor has THREE measured steps of it, played in
# turn, because one step repeated under every foot is the sound of a machine
# walking. See footsteps_init() in rooms.nvgt for the table and the cycling.
#
# A recording of somebody walking is not one cue: the tile, carpet, concrete and
# asphalt files run from half a minute to a minute of somebody walking, so each
# step is an OFFSET into a file - the moment that step actually starts - with a
# 450 ms cut after it. Measured with ffmpeg when they were wired in, so anybody
# can re-check them. "peak" is the level of that step in the file and "gain" is
# what puts every step of a floor at the same heard level, so a walk never jumps
# in volume from one foot to the next. No gain is ever positive.
#
#   floor     file                offset     peak    gain     heard
#   tile      step_tile.mp3         7.02  -10.5 dB     0.0  -10.5 dB
#             step_tile.mp3        10.26   -7.8 dB    -2.7
#             step_tile.mp3        13.26   -6.2 dB    -4.3
#   carpet    step_carpet.mp3       3.60   -4.3 dB    -6.2  -10.5 dB
#             step_carpet.mp3       8.10   -1.3 dB    -9.2
#             step_carpet.mp3      14.10   -2.7 dB    -7.8
#   concrete  step_concrete.mp3     0.00   -0.3 dB   -11.5  -11.8 dB
#             step_concrete2.mp3    3.90  -10.7 dB    -1.1
#             step_concrete2.mp3    7.96  -10.6 dB    -1.2
#   asphalt   footstep.mp3          0.00   -0.1 dB   -11.4  -11.5 dB
#             step_asphalt.mp3      4.42   -9.2 dB    -2.3
#             step_asphalt.mp3      6.72  -11.5 dB     0.0
#
# Concrete and the forecourt end up a few dB below the tile because their steps
# are quieter recordings and no cue is played with a positive gain: a floor whose
# steps are quiet plays quieter rather than louder. Carpet is levelled with the
# tile instead of with the quiet ones, because the recording it used to carry -
# socks and soft shoes on a soft floor - was the one floor nobody could hear at
# all. It is a close-miked walk of shoes on carpet now, and its three steps are
# put at the tile's own heard level so the office and the apartment are as easy
# to walk through as the shop.
#
# Each of those files needs its bundled tone to be silent up to the SMALLEST
# offset the game seeks to in it, or a failed download is silence where the step
# should be. Each placeholder in assets/placeholder/ is that silence followed by
# the usual -26.9 dB tone, running past the largest offset plus the cut. A plain
# short beep would be silent for the whole tile step, which is seven seconds in.
#
# The walls are two more recordings, each a single hit, positioned at the wall you
# walked into: a body against plasterboard in the shop, the office and the
# apartment, sheet metal in the cooler and the freezer.
#
# All seven are CC0 on freesound.org - no attribution is required for any of
# them, and CREDITS.md names the recordist anyway - and every one is the hq
# preview mp3, byte for byte as it was downloaded.

# ---- what the customers' bodies do -----------------------------------------
# The shop's people are bodies before they are baskets: they cough, sneeze,
# sigh, yawn, laugh, clear their throat, huff, hiccup, belch, and their phone
# rings. Every one of these is a real recording, downloaded here like every
# other cue, and every one of them is Public domain or CC0 on Commons - no
# attribution is required for any of them, and CREDITS.md lists the authors
# anyway. None of them was written by this project; there is no synthesiser in
# this game's audio.
#
# These are sessions rather than single cues, which is why the code that plays
# them carries an offset and a cut (see people_emote_offset and
# people_emote_cut_ms in people.nvgt). Measured with ffmpeg: Cough_1.ogg is
# 20.9 seconds long and its first half second sits at -63 dB, which is silence,
# and its loudest 300 ms is at 3.75 s. Playing these from the top would have
# produced silence and a long wait, which is exactly what happened the first
# time they were wired in.
#
# All ten are Ogg Vorbis. That was checked with ffprobe: the engine decodes
# Vorbis but not Opus, and a .ogg can be either.
#
# These are also the only cues the game seeks into, so their fallback tones in
# assets/placeholder/ are not the plain four second beep the other cues use: each
# one is silence up to the cue's own offset and then the same quiet tone, so the
# seek lands on the tone. It has to be that way round. A sigh seeks to 10.4
# seconds, and the tone in its place used to be 4.01 seconds long, so a shop that
# could not reach the host heard no sigh at all and a clipped cough. The tone for
# each cue was built with
#
#   ffmpeg -f lavfi -i "aevalsrc=0.0452*sin(2*PI*440*t)*gte(t\,OFFSET):s=22050:d=TOTAL" \
#          -c:a libvorbis -q:a 2 assets/placeholder/<file>.ogg
#
# where OFFSET is people_emote_offset() and TOTAL is that offset plus the cut plus
# half a second, at the level of the other placeholder tones (-26.9 dB peak).
# Regenerate them and every offset and cut has to fit inside the new tone again,
# or that cue goes silent offline.

# ---- the machines' own chimes -----------------------------------------------
# The terminal and the phone each switch on and off with a sound of their own:
# tech_terminal_on.wav, tech_terminal_off.wav, tech_phone_on.wav and
# tech_phone_off.wav, played by machine_power_sound() in mechanics.nvgt when one
# of their screens opens and when it closes or they log off.
#
# They are NOT listed below and NOT downloaded, for the same reason the four
# generated tracks above are not: they were written for this project and ship as
# files in assets/. Each is a short mono 16-bit 22050 Hz wav - two or three notes
# with a decaying envelope - held at -12 dBFS peak and played at another -4 dB,
# so a machine chime sits under the machine's own voice (the chips play at about
# -5 dB) and over the placeholder tones (-26.9 dB). Nothing here checks their
# byte counts, because a bundled file with no URL has nothing to verify against.
#
# There is deliberately no placeholder tone for them: silence is what a missing
# startup chime should sound like, and a beep where the machine's chime belongs
# would be worse than nothing.
