# Store Express - audio asset manifest
#
# Format:  logical_name|filename|loopable|source_url|bytes
#
#   logical_name  key the game uses (unused at runtime, kept for readability)
#   filename      file the game loads from the live assets/ directory
#   loopable      1 if the game keeps this playing as a loop, 0 for one-shot
#   source_url    where the first-run bootstrap downloads the real recording from
#                 (leave empty to always use the bundled placeholder tone)
#   bytes         the exact size of the recording behind source_url, as fetched
#                 and verified. Optional; leave empty if you do not know it.
#
# On first run the bootstrap walks this list, downloading each source_url into
# assets/<filename>. If a download fails after all retries, the matching file in
# assets/placeholder/ is copied in instead, so the game is always playable.
#
# The bytes column is a repair check. A download that stopped early leaves a file
# that still plays, just clipped, so nothing at runtime can tell it from a whole
# one. Without the size recorded, the bootstrap cannot either, and because it
# skips anything already on disk the damage would last forever. With the size on
# record, a file of the wrong length is deleted and fetched again on the next
# run. Blank means no check.
#
# The codec matters as much as the container. The engine decodes MP3, Vorbis/OGG
# and WAV, but NOT Ogg Opus. A file can be a perfectly valid .ogg and still be
# silent here, which is the same thing that happened to the old Gas-Pump-sound.
# Its replacement above is an MP3. If you add a recording, check the codec
# (ffprobe or `file`) before trusting it.
#
# upload.wikimedia.org rate limits bursts with HTTP 429, so the bootstrap paces
# and backs off. Anything that still fails falls back to the bundled tones.
#
# ---- the shop's speakers ----------------------------------------------------
# Four public domain ragtime recordings, fetched into assets/music/ and played
# through the shop's ceiling speakers when the music is switched on at the
# office computer. The rest of the playlist is not fetched and not listed here:
# those four are written for this project by tools/make_music.py and ship as
# files in assets/music/. Deliberately no placeholder tone for a music track:
# a beep is worse than a missing song, so a failed download here just leaves a
# shorter playlist. They are all MP3.

#
# ---- the machines' own chimes -----------------------------------------------
# The terminal and the phone each switch on and off with a sound of their own:
# tech_terminal_on.wav, tech_terminal_off.wav, tech_phone_on.wav and
# tech_phone_off.wav, played by machine_power_sound() in mechanics.nvgt when one
# of their screens opens and when it closes or they log off. They are NOT
# listed below and NOT downloaded: they were written for this project and ship
# as files in assets/. Nothing here checks their byte counts, because a bundled
# file with no URL has nothing to verify against. There is deliberately no
# placeholder tone for them: silence is what a missing startup chime should
# sound like, and a beep where the machine's chime belongs would be worse than
# nothing.
#
# ---- all other cues: .mp3 or .wav only --------------------------------------
# The shop, the ground floor, the forecourt and the bodies all go out as MP3 or
# WAV. .ogg is only a container: the engine decodes Vorbis but not Opus, and an
# .ogg can be Opus, which is exactly what killed the old Gas-Pump. Nothing that
# the game speaks, walks, touches, or that a machine emits is an .ogg any more.
# The bundled tone for every one-shot cue is a 22050 Hz WAV, and the floor
# recordings are 44.1 kHz stereo MP3s - the same container the game plays, so
# every offset, cut, peak and gain measured with ffmpeg still lines up.
