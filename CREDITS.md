# Audio credits

Store Express ships no third-party recordings in this repository. The real sounds
are downloaded at runtime — from Wikimedia Commons and from Freesound's public
preview CDN — into `assets/`, driven by `assets/manifest.txt`. The files under
`assets/placeholder/` are generated locally by this project from plain sine waves
and are not covered by any of the licences below.

Every URL in the manifest was verified to return **HTTP 200** with real Ogg
Vorbis, MPEG or WAV audio bytes, the exact byte count is recorded as the fifth
column of each manifest line, and every resulting file was loaded and played
through the NVGT audio engine before being credited here.

## A note on the Freesound files

The recordings credited above as Freesound sounds — the shop's own ambience, the
street outside, the pump, the idling car, the television, the squish, the crash,
the swatter's rustle, the punch, the delivery truck, the four floors and the two
walls — are downloaded as **Freesound previews** rather than as the original
uploads. The preview is the copy Freesound serves publicly for the same licence,
it is what a browser would play on the sound's page, and it is the file the
licence above covers. The originals need an account and an API key, which would
mean shipping a credential in a game that must run with no setup at all.

## Generated locally

| File | Origin |
| --- | --- |
| everything in `assets/placeholder/` | Sine-wave tones synthesised by this project with ffmpeg. No third-party rights. They are not plain tones: a cue the game seeks into gets silence up to the offset it seeks to, followed by the usual quiet tone, so the seek lands on the beep rather than on silence. That covers the ten body sounds and every step and wall cue, which are played from partway into their recordings. A file the game seeks to several times, like the tile steps, is silent up to the smallest of those offsets and then tone all the way past the largest one plus the cut. See the notes above those cues in `assets/manifest.txt` for the offsets. |
| `music/day_counter_drift.wav` | Written for this project by `tools/make_music.py`: a daytime loop for the shop's speakers. Synthesised from scratch, so it carries no third-party rights at all. |
| `music/night_after_hours.wav` | Same generator: what the speakers play after dark. |
| `music/chase_back_aisle.wav` | Same generator: the cue that takes the speakers over when a shoplifter runs. |
| `music/fight_ruckus.wav` | Same generator: the cue for two drunks in one aisle. |
| `tech_terminal_on.wav`, `tech_terminal_off.wav` | Written for this project and shipped as files in `assets/`: the terminal switching on and off. Two low notes, up to power on and down to power off. |
| `tech_phone_on.wav`, `tech_phone_off.wav` | Same, made once with the same recipe: the handset, smaller and brighter — three quick blips up, two down. |

The generator is deterministic: mono 22050 Hz 16-bit, no samples, no libraries, a
fixed seed, so re-running it writes the same bytes every time. That is deliberate —
the project can be handed to anybody without a licence question being raised,
which is not true of the commercial music the reference game's build ships.

Two recordings have been retired. `aisle.ogg` was
[1 minute at the alexa mall in berlin](https://commons.wikimedia.org/wiki/File:1_minute_at_the_alexa_mall_in_berlin.ogg)
by thore, and it was the shop floor's ambience and the street outside at the same
time. It is a shopping centre, complete with the music playing in it, so a piano
was audible indoors in a convenience store and a mall was standing in for a road.
Its first replacement, [Checkout Counter at an Asian
Market](https://freesound.org/people/ecfike/sounds/475100) by ecfike, was a
supermarket whose own description mentions a radio playing pop music nearby and a
TV behind the counter — music, indoors, with no way to switch it off. The shop
floor now uses the recording above, which the person who made it describes as
having no music in it.
